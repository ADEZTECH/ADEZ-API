# ADEZ-API

A complete Node.js + Express project for ADEZ API with a working landing page and contact page.

## Features
- Express backend
- Health and status APIs
- Static landing page
- Contact page
- Responsive cyber-tech branding
- Ready to run locally

## Run the project
```bash
npm install
npm run dev
```

Then open:
- http://localhost:3000/
- http://localhost:3000/contact
- http://localhost:3000/api/health

## Project structure
```text
src/
  app.js
  server.js
  controllers/
    healthController.js
  middleware/
    errorHandler.js
    notFound.js
  routes/
    index.js
public/
  index.html
  contact.html
  styles.css
  script.js
```
